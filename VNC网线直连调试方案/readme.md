本方案适合使用网线直连机器人小电脑进行调试车机，使用VNC协议图形化界面操作

### 使用方法：
1.详细的使用指南见vnc_installation_guide.txt

2.或者更便捷的方式是直接使用install_vnc.sh脚本一键安装，然后使用setup_vnc_autostart_v2.sh配置环境和启用开机自启功能

3.建议服务端（车机）和客户端（开发者电脑）都进行以上安装，在用remmia连接时请参考使用指南第9点

4.若出现“VNC服务异常”“黑屏“等情况，可以运行这边给出的fix修复脚本，尝试刷新VNC服务

### 常见问题：
1.有时黑屏，可能是ip输入错误，注意端口为5902,冒号使用英文的

2.注意客户端ip要和服务端ip在同一网段

3.车机ip有时可能冲突，尝试更改车机ip来解决
